# 项目命名指南

依据：软件可持续性研究所（SSI）命名指南与开源项目命名实践。命名是项目第一个品牌决策，值得花 30 分钟而不是 30 秒。

## 好名字的判断标准

1. **能猜到是干什么的**：新人看到名字 + 一句话描述，能大致判断项目用途
2. **短、好念、好拼**：口头转述不需要重复解释；生造的长缩写（如 `XYZMGR`）是负资产
3. **有区分度**：在同类软件里搜一下，和知名项目、同领域项目不撞车
4. **可成长**：不把名字绑死在当前功能上（避免叫 `todo-list` 结果长成工作流平台）
5. **跨语言/跨文化安全**：拼音、缩写在其他语言里没有负面含义

## 起名技巧（发散阶段用）

- **取核心动作/意象**：笔记 → `note / ink / leaf`；看板 → `board / flow / lane`；监控 → `radar / pulse / hawk`；报告 → `quill / brief / digest`
- **组合后缀**：`-ly`（notely）、`-kit`（docskit）、`-hub`（taskhub）、`-flow`（mailflow）、`-pilot`（readpilot）
- **直接用一个喜欢的词**：完全合法且常见（如 `BANG`），不必强行凑缩写
- **造词**：独特性最强、撞名率最低（如 `zustand`），但需要多轮搜索确认无不良含义
- **数量要求**：先列 5-10 个再筛，只列 2 个容易全撞车

## 命名流程（第 1 步用）

1. **发散**：围绕项目核心动作/意象列 5-10 个候选
2. **初筛**：按上面 5 条标准砍到 2-3 个
3. **撞名检查**（每个候选都做，结果填入检查表）：
   - GitHub：`gh search repos "<名字>" --limit 5` 或网页 `github.com/search?q=<名字>&type=repositories`，看是否有同领域同名仓库
   - npm：`npm view <名字>`（有返回=被占用）或 `npmjs.com/search?q=<名字>`
   - PyPI：`pip index versions <名字>` 或 `pypi.org/search/?q=<名字>`
   - 搜索引擎：搜「`名字` software」「`名字` <领域关键词>」，翻 2-3 页，重点看是否同领域
   - 域名：`<名字>.app / .dev / .io` 是否可注册（重要性已下降，撞了可不查）
4. **给选项**：以检查表形式给用户 2-3 个候选，每个附含义、长度、撞名结果、推荐理由

## 撞名检查表（给用户看时用）

| 候选名 | 含义/理由 | GitHub | npm/PyPI | 搜索结果 | 域名 | 结论 |
|--------|-----------|--------|----------|----------|------|------|
| `lumen` | 轻量、发光 | 已有同名框架 | 已被占用 | 同名 PHP 框架排名靠前 | — | ❌ 撞知名项目 |
| `notely` | 笔记应用 | 无同名仓库 | 可注册 | 结果均为无关词汇 | notely.app 可询 | ✅ 推荐 |

## 命名格式约定（落仓库/包名时）

| 位置 | 格式 | 示例 |
|------|------|------|
| GitHub 仓库名 | kebab-case | `mind-garden` |
| npm 包名 | 小写，可有 `-`，与仓库名一致 | `mind-garden` |
| Python 包（import 名） | snake_case，去连字符 | `mind_garden` |
| Go module | 全小写域名路径 | `github.com/user/mindgarden` |
| 页面标题/品牌展示 | 原样大小写或空格 | `Mind Garden` |

## 常见坑（主动提醒）

- **凑缩写**：为了好听的缩写硬改单词拼写，用户记不住也拼不对
- **撞商标**：候选名与知名商业产品同名同领域（如起名 `Notion`）→ 有法律风险，直接排除；跨领域重名风险低，但 README 里注明「与 XX 无关」
- **仓库名与包名不一致**：尽量统一，减少用户安装时的困惑
- **内部黑话外流**：团队代号（科幻梗、内部系统名）对外部用户无意义，开源/对外项目避免
- **连字符歧义**：多词拼接可能连出别的意思（如 `Books Exchange` → `booksexchange`），读一遍再定

## 命名风格速查

| 风格 | 例子 | 适合 |
|------|------|------|
| 功能直述 | `pdf-parser`、`news-report` | 工具库、内部项目 |
| 隐喻意象 | `phoenix`、`beacon` | 对外产品、需要品牌感 |
| 造词 | `vercel`、`zustand` | 独特品牌，撞名风险最低 |
| 人名/地名 | `tesla`（不推荐蹭名人） | 一般避免 |
