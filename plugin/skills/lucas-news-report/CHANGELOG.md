# Changelog

本文件记录 lucas-news-report 的版本演进。版本号规则见 `SKILL.md`「版本管理」。

## [1.2.0] — 2026-11-26

### Changed
- **专业编辑标准：融会贯通，反机械分层**——背景从 5W1H 问答填表改为 2-4 段连贯叙事；各方反应从逐条来源罗列改为立场概述 + 观点对照叙述；同一事实只展开一次、他处交叉引用；节间承上启下。SKILL.md「完整报告」核心准则重写（「模块化分析」改为「融会贯通」），主流程整合分析步改为「先定叙事主线、再按模块取材」。遵 CLAUDE.md「按专业编辑标准组织内容」新规。
- **时间线标准升级**——节点 = 时间 + 事件 + 意义/影响（不只写"发生了什么"，写清"改变了什么"），转折点显式标注、关键节点带来源；默认表格（时间 | 事件 | 意义/影响 | 来源），mermaid 按需；解读从「起点→转折→当前状态」套话升级为发展逻辑（各方动作如何互相触发、当前阶段、下一步观察什么）。模板 §二/§三/§四与自查清单同步。

## [1.1.2] — 2026-11-26

### Changed
- **结尾禁附免责 / 特别说明尾巴**：报告与博文版结尾不再写「（以上信息来自公开渠道，观点仅供参考，欢迎交流。）」这类免责式尾巴——遵 CLAUDE.md「按专业标准交付」新规，信源边界由「信息来源索引 + 可信度分级」承担。SKILL.md「输出与存放」新增条目，两个模板自查清单同步。

## [1.1.1] — 2026-09-08

### Removed
事件报告与通俗博文两个模板同步删除结尾出处块示例与自查项。- **文末出处块**：产出文档不再附文末三行出处块（作者/版本/出处）——CLAUDE.md 已全局废除该规范，产出保持自解耦、不含仓库/skill 内部信息。SKILL.md 与模板同步删除相关指引、示例与自查项。

## [1.1.0] — 2026-08-12

### Added
- **多平台采集新增「图片采集」——让报告"有图有真相"**。原报告纯文字，现在采集时同步收集四类关键图片：官方截图（公告/声明/发布会 PPT）、数据图表（评分/性能/舆情趋势）、事件产品照片、社交高赞反应截图（模糊隐私）。获取方式：WebFetch 内容中留意图片 URL，或 `curl -sL "<url>" | grep -oiP '<img[^>]+src="\K[^"]+"'` 扫页面图片地址再下载。嵌入配事实性 caption + 来源索引交叉引用，无图不硬凑。SKILL.md「多平台采集」节加「图片采集」子节，`references/platforms.md` 加各渠道重点图片类型表。
- **报告与博文新增封面图**。报告标题后、博文正文开头放一张事件氛围图——优先用采集中最代表性的实拍/截图；无合适图时用 picsum.photos（`seed=<slug>-<timestamp>`，每次不同）。报告模板、博文模板加封面图占位与注释；SKILL.md「输出与存放」frontmatter 加 `cover` 字段、目录结构 `imgs/` 描述更新。

### Changed
- `assets/report-template.md` 在背景、官方反应等节加内嵌图片占位（配事实性 caption 注释）。
- `assets/blog-post-template.md` 封面图注释更新（seed 用 slug+timestamp），"这事到底怎么回事"节加事件图占位。

## [1.0.0] — 2026-08-04

### Added
- 初始版本：新闻/热点事件多平台深度调研与完整事件报告。
- 主流程：intake → 核验（两道确认门：真实存在/消歧 + 疑似谣言标记）→ 多平台采集（官方/权威媒体/社交平台/用户评价/垂直专业五类渠道）→ 整合分析 → 完整报告 → 可选博文版。
- 核验护栏：无可靠报道/多事件歧义/疑似谣言时停下与用户确认，避免在模糊信息上盖报告——区别于文献检索类 skill 的"绝不追问"，因新闻事件无稳定标识、同名实体多、时效性强，确认门是负责任的体现而非啰嗦。
- 完整报告模块：事件核验、背景与核心事实（5W1H）、时间线（mermaid）、各方反应（模块化）、模块化分析（影响/争议/对比）、信息缺口与 uncertain、信息来源索引（信源可信度分级）。
- 博文版（可选）：基于完整报告的通俗发布版，tone 参考 `lucas-paper-blog` 的通俗/互动/作者在场，内容对象为事件而非论文。
- `references/platforms.md`：五类渠道检索词构造、典型入口、注意事项 + 按事件类型裁剪平台 + 信源可信度分级表。
- `assets/report-template.md`：完整事件报告骨架模板（含 frontmatter + 各模块 + 时间线 + 来源索引 + 自查清单）。
- `assets/blog-post-template.md`：博文版骨架模板（含 frontmatter + 各节 + 自查清单）。
- 与体系内其它 skill 分工：明确与 `lucas-paper-search`（论文检索）、`lucas-paper-read`（论文精读）、`lucas-paper-blog`（论文博客化）、`lucas`（反省）的边界——本技能专注新闻/事件调研，博文版与论文博客内容对象不同、不互替。
- 遵 CLAUDE.md：单一源 `skills/lucas-news-report/`、发现层 symlink、文档输出规范（三行出处块、段落不硬换行、frontmatter 保留）、后续衔接提示。
