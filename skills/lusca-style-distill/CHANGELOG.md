所有版本变更记录。版本号规则：MAJOR（流程/输出规范 breaking）/ MINOR（新维度、新 reference、新模板侧重）/ PATCH（措辞、typo）。

## [1.0.0] - 2026-08-04

### Added
- 首版：写作风格提取技能。给一篇文章（或同一作者的若干篇），按 6 维度（语态与人格 / 句法指纹 / 用词癖好 / 修辞与意象 / 节奏与结构 / 立场与论证姿态）抽出带原文佐证的风格 DNA，产出含签名清单、可迁移 Do/Don't、反例的复用画像。
- **核心准则**：每条判断必带原文佐证（不脑补、不甩无从核对的形容词）、可迁移清单写具体动作（不写"语言生动"这类空话）、给反例防滥用、风格≠内容（只抽"怎么说"，内容对错交给 `lusca-paper-read`）。
- **两套文体模板**：内置通用文章（专栏 / 科普 / 散文 / 评论 / 叙事）与学术/技术写作两套模板，6 维度统一但侧重不同——通用重 A 语态人格 / D 修辞意象 / E 节奏结构，学术重 B 句法（时态主被动）/ C 用词（术语引用纪律、claim 校准）/ F 立场（claim 校准、公允度、限定语）。文体自动判定、用户明示优先。
- **单篇 vs 多篇**：单篇出风格画像；多篇合并出作者 DNA，区分稳定特征（贯穿 ≥2 篇 / 高置信）与一次性文风（仅见于单篇 / 低置信），矛盾信号分模式标注不硬揉，小样本（1–2 篇）如实降级表述。
- `references/style-dimensions.md`：6 维度的判定信号查表 + 每维原文佐证要求 + 学术/技术变体侧重 + 常见误判 + 通用 vs 学术整体侧重表。
- `references/multi-article-merge.md`：稳定 vs 偶发判定、矛盾信号分模式、跨篇取样、置信度写法、小样本如实说明、多篇 vs 单篇输出差异表。
- `assets/general-template.md`、`assets/academic-template.md`：两套输出骨架 + frontmatter + 落盘前自查清单。
- 与体系分工：本技能管"怎么说"（风格），与 `lusca-paper-read`（"说什么"）正交；与 `lusca-paper-polish`（润色你自己文字、保留你的声音）边界清晰——本技能抽取别人的风格供参照，不替你改你的字。
- 后续衔接：`/lusca-paper-read`（对同一篇吃透内容）、`/lusca`（复盘提取尺度）。
- 文末出处块、段落不硬换行、frontmatter 保留等文档输出规范遵 CLAUDE.md。
- 参考了 `3rdparty/cangjie-skill` 的「每条带原文佐证 + 原子可执行 + 反例边界」三条思想；未采用其并行多 extractor / RIA-TV++ 重型流水线 / meta-skill 生成 skill 的形态——风格维度相互纠缠，一人通读贯通比并行孤立提取更准，且本 skill 是单职责工具而非 meta-skill。
