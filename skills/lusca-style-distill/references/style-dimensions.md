## A. 语态与人格 (Voice & Persona)

作者"在场感"的样子——读起来像谁在说话。

**判定信号**（扫到这些就记一笔）：
- **人称**：第一人称单数（"我认为"）/ 第一人称复数（"我们"——含读者 vs 仅作者团队）/ 第二人称（"你"）/ 全文隐去人称的客观腔
- **与读者的关系**：平辈交谈 / 师长授课 / 对手辩论 / 朋友闲聊 / 旁观陈述
- **态度**：诚恳 / 戏谑 / 冷峻 / 热切 / 超然 / 居高临下 / 自嘲
- **权威感来源**：经验（"我做过 X"）/ 数据 / 逻辑推导 / 身份 / 引用大佬
- **幽默浓度**：无 / 点缀 / 密集；幽默类型（冷幽默、自嘲、反讽、打趣）
- **情绪外露程度**：克制零情绪 / 适度 / 强烈（感叹号、强形容词）

**佐证要求**：人称与态度必须引一句带主观色彩或带"我/你"的原句；权威感来源要引出"靠什么承重"的那句。

**学术/技术变体**：传统学术文刻意**压制**人格——隐去人称、用被动语态、零幽默、零情绪；但技术博客、综述
型学术专栏、观点类论文会**强化**第一人称与态度。判定时要分清"传统期刊体"还是"学术专栏体"，两者语态
差别很大，别混为一谈。

**常见误判**：把"克制"当"没人格"。学术文的克制本身就是一种语态选择（客观腔），要标成特征而非"无特征"。

## B. 句法指纹 (Syntax)

句子怎么搭——长度、结构、标点的习惯。

**判定信号**：
- **句长分布**：取一段连续 5–8 句数字数。全短（多数 <15 字）= 短促断句型；长短交替 = 节奏型；全长（多数
  >30 字）= 铺陈型；碎片句（词或短语独立成句）= 断裂型
- **句式偏好**：排比（同结构 ≥3 句）/ 倒装 / 主动 vs 被动 / 省略句 / 整句对仗
- **问句**：设问（自问自答）/ 反问 / 真提问；出现频率
- **收尾习惯**：重音压句末（periodic，关键信息最后才给）/ 重音在句首（loose，先给要点再展开）
- **标点癖好**：破折号（补充/转折）/ 分号（并列长句）/ 省略号（留白）/ 冒号（引出）/ 引号（特殊用法）/
  括号（插话）/ 全大写 / 斜体 / 粗体——各自频率

**佐证要求**：句长判断要引连续数句的原句；标点癖好要引含该标点的原句（多个则引 2–3 处证稳定）。

**学术/技术变体**：
- **时态纪律**（学术文核心）：陈述事实用现在时、报告实验用过去时、引述他人工作用现在或过去——抓作者的
  时态分配习惯，混乱或一致都是特征
- **主被动选择**：传统学科偏好被动（"was measured"），CS/现代期刊倾向主动 + "we"；同一作者跨节混用也算特征
- **名词化堆叠**：学术文易堆"……的分析与优化"这类名词化短语，密度是辨识点

**常见误判**：只看单句。句法特征要**连续多句**才稳——一句短不代表短促型，要看出节奏。

## C. 用词癖好 (Diction)

词汇层面的偏好与签名。

**判定信号**：
- **语域**：正式 / 口语 / 文白夹杂 / 中英混排；学术文看是否过度口语或过度生硬
- **抽象 vs 具象**：偏好抽象大词（"本质""范式""张力"）还是具象小词（"杯子""门槛""扳手"）
- **术语密度**：术语占比、术语是否首次出现配解释
- **签名词与口头禅**：反复出现的标志性词或短语（"换句话说""说白了""值得注意的是"）
- **对冲词 vs 强化词配比**：对冲（"可能""也许""在某种程度上"）与强化（"显然""必然""无疑"）的比例——
  反映作者的确定性姿态
- **古语 / 外来词 / 行话**：是否爱用文言、英文原词、特定圈子黑话

**佐证要求**：签名词与口头禅要引 ≥2 处原文证"反复"；对冲/强化配比引代表性的各一处。

**学术/技术变体**：
- **术语一致性**：同一概念是否贯穿用同一个词，还是中途换说法——学术文术语漂移是硬伤，稳定是特征
- **缩写引入规范**：是否"全称（缩写）"首次定义后用缩写，规范与否是辨识点
- **claim 校准词**（学术文核心）：用词强度是否匹配证据——`show/demonstrate`（强）vs `suggest/indicate`
  （中）vs `may/appear to`（弱）的分配习惯。可参考 `lusca-paper-polish` 的措辞阶梯，但这里只**观察描述**
  作者的用法，不改写

**常见误判**：把"用了个生僻词"当签名词。签名词要**反复出现**才算签名，一次性用词不算。

## D. 修辞与意象 (Rhetoric & Imagery)

怎么用比喻、类比、反复来达成效果。

**判定信号**：
- **比喻 / 类比频率**：几乎不用 / 偶尔解释概念时用 / 密集贯穿
- **取材域**（关键）：比喻从哪取材——体育 / 烹饪 / 军事 / 生物 / 机械 / 日常生活 / 棋牌 / 身体 / 商业 ……
  作者反复从同一域取材就是签名
- **修辞手法**：排比 / 三连（rule of three）/ 反讽 / 夸张 / understatement（轻描淡写）/ 重复 / 对偶
- **母题与原型意象**：反复出现的同一类意象（如反复用"光/暗""路/门""潮水"）

**佐证要求**：每个修辞判断引一处原文实例；取材域要引 ≥2 处同类比喻证"反复从这域取材"。

**学术/技术变体**：学术文**刻意压制**修辞——比喻只在解释抽象概念时才用（类比作脚手架，不当装饰），
母题与意象基本缺席。技术博客相对宽松。判定学术文时，"修辞稀薄、类比只服务于解释"本身就是一条特征，
而非"无修辞可写"。

**常见误判**：把一个精巧比喻当"爱用比喻"。要看**频率与取材域的稳定性**，单个比喻不够。

## E. 节奏与结构 (Rhythm & Structure)

行文的推进方式——开篇、过渡、收尾、段落切分。

**判定信号**：
- **开篇套路**：轶事 / 大胆断言 / 提问 / 场景描写 / 数据冲击 / 定义切入 / 引用他人
- **段落长度与切换**：均匀短段 / 长段铺陈 / 长短交替；段与段之间是硬切还是软接
- **过渡方式**：用什么词或结构承上启下（"但是""换句话说""再往远看""问题来了"）
- **收尾习惯**：回扣开头 / 反转 / 祈使号召 / 留白 / 金句 / 开放提问
- **列表 vs 散文**：偏好连续散文，还是爱用列表 / 小标题切块
- **离题与插话**：是否频繁跑题、用括号或破折号插话、再拉回主线
- **信息密度节奏**：紧—紧—紧，还是松—紧—松，信息是匀速给还是突然堆

**佐证要求**：开篇引首段、收尾引末段；过渡方式引 2–3 处过渡词原句证习惯。

**学术/技术变体**：
- **段落主题句习惯**：是否每段以一句 topic sentence 开头、后接支撑——学术文的段落纪律比通用文严格
- **章节结构意识**：是否遵循 IMRaD 或类似骨架、节间有无"承上启下"的过渡段
- **图表指代习惯**：怎么把读者引向图表（"as shown in Fig. X""见表 1"），是否让正文与图表重复

**常见误判**：只看开头结尾。节奏要看**中段怎么推进**——开收头好抓，中段习惯才是真签名。

## F. 立场与论证姿态 (Stance & Argumentation)

作者怎么立论、怎么对待反对者、怎么用证据。

**判定信号**：
- **确信度**：斩钉截铁 / 留有余地 / 高度 hedging
- **如何对待异见**：直接驳斥 / 委婉让步再转 / 假装不存在 / 树稻草人
- **如何让步**："诚然……但是……"式结构出现的频率与诚意
- **证据承重方式**：用数据 / 引用权威 / 案例 / 逻辑推导 / 个人经验 来撑论点；哪种为主
- **诉求类型**：诉诸逻辑（logos）/ 情绪（pathos）/ 权威（ethos）的比例
- **对读者的预设**：默认读者已认同 / 需要被说服 / 是对手 / 是小白
- **预判反驳**：是否主动提出"有人会说……"再回应

**佐证要求**：确信度与让步各引一处原句；证据承重方式引一段代表性论证。

**学术/技术变体**：
- **claim 校准姿态**（学术文核心）：claim 是否始终跟着证据强度走，还是跑在数据前面（"prove"用在薄弱
  证据上 = 过度主张）。这是学术风格的关键辨识点，也是 `lusca-paper-polish` 校准的对立面——本技能只观察
  描述，不改正
- **公允度**：转述他人工作时是精确说差异，还是压成稻草人衬托自己（参考 polish 的"公允对待已有工作"）
- **限定语纪律**：是否系统地用"仅在此数据集上""在 X 条件下"等限定语圈定结论边界

**常见误判**：把"自信"等同于"确信度高"。要区分**语气自信**与**claim 是否真有证据撑**——两者可能错位。

## 通用 vs 学术/技术的整体侧重

同一篇文章不需要把 6 维平均用力——按文体调权重：

| 维度 | 通用文章侧重 | 学术/技术侧重 |
|------|------------|-------------|
| A 语态人格 | **重**（人格是通用文的魂） | 轻（传统学术压制人格；专栏体例外） |
| B 句法 | 中（节奏、标点癖好） | **重**（时态、主被动、名词化） |
| C 用词 | 中（语域、签名词、对冲强化配比） | **重**（术语一致性、缩写规范、claim 校准词） |
| D 修辞意象 | **重**（取材域、母题） | 轻（压制；类比只在解释概念时） |
| E 节奏结构 | **重**（开收尾、过渡、段落节奏） | 中（段落主题句、章节骨架、图表指代） |
| F 立场论证 | 中（确信度、诉求类型） | **重**（claim 校准、公允度、限定语纪律） |

判定为学术/技术时，B/C/F 三维要展开讲透；通用时 A/D/E 三维要展开讲透。这不是说其余三维可以糊——每维
都要有判断 + 佐证，只是**深度与篇幅**向侧重维度倾斜。
