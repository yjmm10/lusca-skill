# Changelog

本文件记录 lusca-news-report 的版本演进。版本号规则见 `SKILL.md`「版本管理」。

## [1.0.0] — 2026-08-04

### Added
- 初始版本：新闻/热点事件多平台深度调研与完整事件报告。
- 主流程：intake → 核验（两道确认门：真实存在/消歧 + 疑似谣言标记）→ 多平台采集（官方/权威媒体/社交平台/用户评价/垂直专业五类渠道）→ 整合分析 → 完整报告 → 可选博文版。
- 核验护栏：无可靠报道/多事件歧义/疑似谣言时停下与用户确认，避免在模糊信息上盖报告——区别于文献检索类 skill 的"绝不追问"，因新闻事件无稳定标识、同名实体多、时效性强，确认门是负责任的体现而非啰嗦。
- 完整报告模块：事件核验、背景与核心事实（5W1H）、时间线（mermaid）、各方反应（模块化）、模块化分析（影响/争议/对比）、信息缺口与 uncertain、信息来源索引（信源可信度分级）。
- 博文版（可选）：基于完整报告的通俗发布版，tone 参考 `lusca-paper-blog` 的通俗/互动/作者在场，内容对象为事件而非论文。
- `references/platforms.md`：五类渠道检索词构造、典型入口、注意事项 + 按事件类型裁剪平台 + 信源可信度分级表。
- `assets/report-template.md`：完整事件报告骨架模板（含 frontmatter + 各模块 + 时间线 + 来源索引 + 自查清单）。
- `assets/blog-post-template.md`：博文版骨架模板（含 frontmatter + 各节 + 自查清单）。
- 与体系内其它 skill 分工：明确与 `lusca-paper-search`（论文检索）、`lusca-paper-read`（论文精读）、`lusca-paper-blog`（论文博客化）、`lusca`（反省）的边界——本技能专注新闻/事件调研，博文版与论文博客内容对象不同、不互替。
- 遵 CLAUDE.md：单一源 `skills/lusca-news-report/`、发现层 symlink、文档输出规范（三行出处块、段落不硬换行、frontmatter 保留）、后续衔接提示。
