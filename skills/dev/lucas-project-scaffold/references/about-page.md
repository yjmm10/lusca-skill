# 关于页（About）

## 是否要：先给选项

- **A 不做**：单页工具、落地页本身已含信息 → 推荐，省维护
- **B 简版自述**：一个 section 或独立轻页面
- **C 参考页面定制**：用户提供参考页面（链接 / 截图）

## 简版信息结构（B 方案）

一段定位（这是什么、给谁用）+ 特性列表（3-5 条）+ 作者/团队 + 联系方式或仓库链接 + 版本/最近更新时间。不堆砌，能少则少。

## 参考页引用方法（C 方案）

1. 从参考页**提取**：布局骨架（几栏、区块顺序）、信息层级（先讲什么后讲什么）、交互模式（有没有折叠/轮播）——**不抄**配色代码、图片素材、文案
2. 把提取结果**映射到本项目 tokens**：颜色、圆角、字体、间距全部替换为本项目 design token；组件用本项目已有的
3. 参考页与本项目风格差异过大（如参考页是暗色玻璃拟态、本项目是亮色简洁风）→ 先提醒用户确认再动手
4. 版权注意：只借鉴结构与模式，不搬运受版权保护的素材与成段文案

## 验收清单

- [ ] 关于页信息与 README 定位一致，无矛盾表述
- [ ] 全部颜色/间距/字体来自 tokens，无写死值
- [ ] 移动端可读（单栏可折叠）
- [ ] 链接可点（仓库 / 联系方式真实有效）
