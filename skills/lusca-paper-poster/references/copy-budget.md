# poster_copy 字数预算（landscape 60×36）

校验由 `scripts/validate_copy.py` 执行。超预算 → 改短再验，**最多 2 次**（与 fill 的 3 轮门控分开）。

| 字段 | 上限 |
|------|------|
| `problem` | ≤ 3 条；每条中文 ≤ 28 字 **或** 英文 ≤ 18 词 |
| `contribution` | ≤ 3 条；同上 |
| `method` | ≤ 5 条；同上 |
| `results` | ≤ 4 条；同上；**至少 1 条含具体数字**（笔记无数字则写明 `n/a`，禁止编造） |
| `takeaway` | 1–2 句；合计中文 ≤ 80 字或英文 ≤ 50 词 |
| `caveat` | 1 句；中文 ≤ 40 字或英文 ≤ 25 词 |
| `meta.title` | 展示时可截断至 120 字 |

词数：按空白分词。中文按字计（去掉空白）。
