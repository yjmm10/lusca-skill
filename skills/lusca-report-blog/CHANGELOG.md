# Changelog

本文件记录 lusca-report-blog 的版本演进。版本号规则见 `SKILL.md`「版本管理」。

## [1.5.0] — 2026-08-07

### Added
- **frontmatter 新增 `abstract` 字段（≤200 字中文博文摘要）**：用于平台描述/SEO/列表预览，概括"报告讲了什么、说清楚后的图景、对读者意味什么"；与正文 TL;DR（一句话钩子）互补——abstract 是完整段落、TL;DR 是一句话。SKILL.md「输出与存放」节、模板 frontmatter 与自查清单同步。

### Changed
- **`cover` 改为存外链 URL（不再是来源描述），对齐 lusca-paper-blog v1.4.0 的 cover 规范**：原本 `cover` 记文字来源描述（`Bing 每日一图 · <copyright>` 或 `picsum · seed: …`）。合并为 `cover` = 氛围图外链 URL（正文实际引用的图片地址）、新增 `cover_backup`（本地备份路径）与可选 `cover_source`（来源描述，用于溯源/版权标注）。加**硬约束**：`cover` 必须是 http(s):// 开头图片直链，❌ 严禁文字描述（落盘前自检 `cover` 以 http 开头）。SKILL.md「图片与视觉」「输出与存放」节、模板 frontmatter / 氛围图注释 / 自查清单同步。
- **措辞对齐 lusca-paper-blog：「一句话带走」→「一句话总结」**：TL;DR 引导词与正文标记统一改"一句话总结"（paper-blog v1.4.0 已改）。SKILL.md「结构」节、模板 TL;DR 占位与自查清单同步。

### Fixed
- **回溯修正今天（2026-08-07）两篇新产出的 frontmatter**：`minimax-h3-open-source`（cover 由 `picsum.photos · seed: minimax-h3-omni` 改为 picsum 真实 URL）、`qwen36-27b-fable-fusion-711`（cover 由 Bing 文字描述改为石灰窑灯塔 Bing 直链）；两篇补 `cover_source`（原文字）、`cover_backup`（imgs/cover.jpg）、新增 `abstract`（≤200 字摘要）；正文 TL;DR「一句话带走」→「一句话总结」同步。

## [1.4.0] — 2026-08-04

### Added
- **价值导向（博客存在的理由，与总纲互补）**：博文的一切为了给读者提供知识价值——挑高价值、读者真正关心的内容呈现（非机械转录所有模块）；每段有知识增量；围绕读者想知道/该知道的来组织，不围绕报告原结构。**作者的价值靠"筛选 + 组织 + 讲清楚"体现**（让读者"省时间、抓重点、搞清楚"），不靠观点论证。这条补上 v1.3.0"不是论证"的正面目标——整理加工/说清楚是手段，交付知识价值是目的。
- 触发起因：用户提出"要把有价值的内容、用户关注的信息呈现，一切为了给观众提供知识价值、让用户感受到作者的价值"。

### Changed
- `SKILL.md`：核心理念改为以"提供知识价值"立旗（作者价值=筛选+组织+讲清楚，不靠观点）；核心准则置顶新增"价值导向"节（高价值筛选/每段知识增量/围绕读者组织）；主流程 Step 2 改为"读透+筛选"（挑高价值、读者关心的，不必搬所有模块）、Step 3 强调围绕读者想知道的组织、Step 5 加"删凑数段"；"澄清式作者在场"节呼应价值导向；description 补价值导向条款。
- `assets/report-blog-template.md`：顶部注释加价值导向；正文注释加"先筛选：挑高价值、读者关心的，围绕读者想知道的组织，每段问'读者拿到了什么'"；自查清单首位加价值导向检查。

## [1.3.0] — 2026-08-04

### Added
- **总纲：整理加工、把事情说清楚，不是论证（凌驾其它准则）**。博文定位为对信息的整理加工，不是论证文——作者穿插澄清而非观点论证。
- **三不设（硬规矩）**：不设"我怎么看/我的看法"节、不设"时间线"节、不用"冷静一下/注意事项"割裂附录标签。
- **"关键来源" → "参考来源"**：呼应整理加工定位（供查证），非论证证据。

### Changed
- **与 v1.1.0"不要标签分节"reconciliation**：按视角组织（官方/媒体/社区）是允许的（帮读者看清各方怎么说）；真正被禁的是评论/评价/证据框架（我怎么看/时间线/关键来源）。结构选择服从"哪个讲得更明白"。

## [1.2.0] — 2026-08-04

### Added
- **输出解耦（硬约束）**：博文自包含、与源报告解耦——不嵌入完整报告原文；资源块只放外链不放本地报告路径；本地文件除 imgs 外不引用；frontmatter source_report 只写报告标题。

### Changed
- 各方视角综合补充"可枚举的多点观点推荐用分点列表"。

## [1.1.0] — 2026-08-04

### Changed
- 结构重构：各方视角综合成自己的话、作者判断 inline 不单设"我怎么看"节、时间线按需、caveat 用连贯过渡。（v1.3.0 以总纲统摄并放宽了"不标签分节"的过度解读。）

## [1.0.0] — 2026-08-04

### Added
- 初始版本：把一份报告转成通俗可发布的博文。定位为 `lusca-paper-blog` 的风格同源、领域不同的兄弟技能。
