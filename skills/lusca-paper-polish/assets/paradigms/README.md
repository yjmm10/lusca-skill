# 润色范式索引（per-section paradigms）

## 定位（与 references 的分工）

- `references/section-conventions.md` 讲**各节该说什么**（必答问题、顺序、常见毛病）；
- `references/academic-phrasebank.md` 讲**怎么说**（动词阶梯、替代表达）；
- `references/ai-tone-guardrails.md` 讲**怎么去 AI 腔 / 软化注水**；
- 本目录（`assets/paradigms/`）讲**按什么范式与深度组织 + 审稿人会怎么挑刺**——每节一个文件，
  按需 Read，不必全读。
- **本 README 是全局层**（类型判断 + 各节维度速查 + **整篇一致性核查表** + 总信条）：整篇润色先读它、做**全局体检**（查跨节一致性）；**各节 `<节>.md` 是局部层**：精修某一节时按需 Read 对应文件，做**局部优化**。两层分工不重复——README 兜跨节硬伤，各节文件管单节深度。

润色不是无差别改通顺，而是按章节职责把**该凸的凸出来、分散的收拢、缺位的补位**，同时守住
**审稿人视角的严谨性底线**（哪些是会被挑刺的隐性硬伤）。

## 先认准论文类型（用错变体是常见硬伤）

每节都区分**研究型**（research：提出新方法 + 自己的实验）与**综述型**（survey/review：梳理领域 + 指出空白 + 指引方向）两种变体。先判类型再选骨架——给综述套"我们提出 X，提升 Y%"、或给研究型写"本文为读者提供完整知识框架"，都是错位。

## 各节专属审稿维度速查

润色某节时，除通用的 faithfulness / 校准 / 去 AI 腔外，按该节专属维度重点核查：

| 节 | Read 文件 | 专属审稿维度 |
|---|---|---|
| 摘要 | `abstract.md` | 证据锚点 / 可证伪性（声称"全面/填补空白"须有正文矩阵撑） |
| 引言 | `introduction.md` | 贡献可验证 + 差异化坐标 + 导航图-正文对应 |
| 相关工作 | `related-work.md` | 符号-备注一致 + 建设性否定（缺陷定位+本文补位） |
| 方法/框架 | `methods.md` | 图自解释 + 分类正交完备 + 缩写首现全称 + 物理约束不漏 |
| 实验/评估 | `experiments.md` | 控制变量 + 数字带前提 + 局限真诚（Limitations 专列） |
| 结论 | `conclusion.md` | 未来方向三要素（问题+使能技术+目标）+ 首尾闭环回链引言 Gap |

## 整篇体检：全局一致性核查表

逐节润色易"只见树木"。**交付整篇前（或用户要求"排查 / 体检 / 审稿"时）必须 `Read` 全文一遍**，按下表横向核查，输出问题清单——**只标注、不擅自改**数据 / 公式 / 结构，数据与推导类一律标"待作者确认"。这是逐节润色的**兜底**，与各节文件的正向范式互补。

| 核查项 | 查什么 | 典型违反（实例） |
|---|---|---|
| 跨节数字/参数一致 | 同一参数（$B$、$N$、$T$、阈值）在正文 / 表 / 图注 / caption 前后一致 | 图 1 caption "$B{=}3$" vs 表 1 "$B{=}1$" vs 正文"本文实验取 $B{=}1$"（迭代遗留） |
| 公式量纲一致 | 跨节公式同一物理量量纲一致；参数标注与定义吻合 | §5.1.2 $E_\mathrm{tot}$ 缺 $\tau$ vs §3.1 $\Delta E{=}P_f\tau$ vs 表 5-3b 含 $\tau$；"$P_f/E_\mathrm{cap}$"应为"$P_f\tau/E_\mathrm{cap}$" |
| 符号/缩写首现定义 | 缩写、符号首次出现给全称/定义；跨节符号同义不冲突 | — |
| 术语跨节统一 | 同一概念全篇一个叫法 | §1.4"骨干相关" vs §5/§6"骨干依赖" |
| 表/图编号体系 | 编号连续、体系统一（不"表 1/3/5-X"混用、删表后跳号、两套图号并存） | 删表 2 后"表 1→表 3"跳号；"表 3"与"表 5-X"两套混用 |
| 引用闭环 | 正文引用的图表/文献/附录都存在，无悬空引用 | 删表 2 后"见表 2"残留（引用未同步删） |
| 图表互补不重复 | 图给可视化/架构/权衡、表给精确数值/多维对比；同主题不重复呈现 | §4.1 已有架构图（图 2）又列同主题 2 行小表（信息是图子集），删表由 caption 承载 |
| 文字跨节不重复 | 同一论点/闭环不在多节整段重述；小结不等于结论的复刻 | §4.3.5"感知-行动闭环"整节 vs §4.1+图 2 已讲闭环；§5.7 小结 vs §6 结论三点近乎逐字重复 |
| 章节衔接 | 节间有承接句（上节末引出下节、下节首回扣上节），不各管各的硬拼 | §2 相关工作 到 §3 系统建模 缺过渡句（突跳） |
| 内容严谨（标注不修） | 推导可复现、claim 有据、无逻辑跳步；量纲与定义吻合 | §3.2 $\delta_u$ 推导跳跃（$\tilde{\delta}_u{=}R_\mathrm{span}/u$ 得 3.4–17，表却 7–32，"$\tilde{\delta}{\to}\delta$"不透明），标"建议作者补换算"，**不替写** |

## 总信条（顶刊审稿人的连环追问）

> 用矩阵代替形容词，用符号代替模糊，用局限代替吹嘘，用闭环代替发散。

每一句话都要经得起三连追问：**为什么这么说 / 证据在哪 / 那又怎样**。表格、图表、符号不是装饰，
而是构建自证逻辑链的承重墙。

## 边界重申（范式不凌驾于诚信之上）

范式与审稿维度都指导**方向与深度**，但下述准则优先级更高，冲突时以它们为准：

- **忠实本意 / 绝不臆造**：补内容只用原稿已有要素；原文没有的数据、机制、引用一律不加。
- **校准**：措辞强度匹配证据；"显著/大幅/全面"等词要有实质撑。
- **公允**：不压低 prior work 来衬托本文（相关工作尤其）。
- **去 AI 腔**：所有模板句/高频词**借鉴非套用**；不承载信息的套话一律删。
- **论文类型别选错**：研究型/综述型变体不可混用。

"突出亮点、避免短板"是**组织策略**（该凸的凸、limitations 不在摘要展开），**不是**授权注水或隐瞒。
