# 论文结构解耦与格式规范

> **何时读**：润色系统模型 / 问题建模 / 方法等"理论章节"，或整篇体检时。本文件讲**跨节的结构纪律**——
> 理论与实验解耦、符号出场、图表与命名规范——与 `section-conventions.md`（各节该说什么）、
> `assets/paradigms/`（各节怎么组织）正交：那两份讲"内容职责与写法"，本份讲"跨节硬纪律"。
>
> 判定口径：每读一句，问"这是通用模型的设定，还是某次实验的实例？"——属后者即移出理论章节。

## 一、理论章节与实验 / 代码解耦

建模 / 系统模型 / 问题形式化章节只讲**通用变量与理想化场景**。下列内容属实验或实现层，不得写进理论章节：

- **实验取值**：具体数值参数（$B=1$、$n=18$、"本文取 $u_{\mathrm{th}}=U-1$"）。数值是实验配置，归实验章节的参数表；理论只保留符号与关系。
- **实验处理方式**：种子生成、对比实验共用计划、确定性工作负载、在线 / 离线工程细节——属实现层，移实验章节或删。
- **代码引用**：「见开源代码」「具体取值见仓库」。论文须与代码自解耦（与 SKILL.md「输出与存放·自解耦」一致）。
- **算法提前绑定**：模型 / 问题阶段就写「以 QMIX / 算法 X 实现」。具体算法在方法或实验章节引入；理论保持骨干无关。
- **实验预演表述**：「机制验证实验以最大化 X 为目标」——把实验目的写进理论，混淆层次；理论只定义目标函数，实验目的归实验章节。
- **章节预告**：「第五节将以 X 为主报告指标」。理论章节不预告实验如何呈现。

> 在线推断 vs 离线标注要说清：若理论涉及"推断"动作（如某模块在线读取输入），须明确其触发时机（如"任务释放即触发在线推断"），不得写成"提前已标注好"——否则方法机制被误读。

## 二、符号与公式出场纪律

- **首次定义处才用**：不在定义前 forward-reference。§3.3 不该用 §4.3 才定义的 $s(j,i)$；要用就先定义，或改文字描述并标（§4.3）。
- **引言 / 相关工作 / 贡献清单不嵌公式**：这些章节讲"做什么、为什么"，不展开数学；公式（含 $s(j,i)$、$1/(1+d)$ 这类片段）留给方法 / 形式化章节。贡献清单用文字描述机制即可。
- **派生量与冗余符号清理**：引入却未被任何公式 / 约束消费的状态量（如只为写递推而设、后续无人用的 $B_i(t)$）、引入却没进最终公式的符号（如路径倍率 $\lambda$）——删或并入正文。

## 三、图与表

**图说**：

- 只留基本说明（「图 1 系统模型示意图」）。不描述图内数据流、模块连线、符号、参数值。
- 删脚手架文字：「（占位·待绘）」「18×18、$N=5$ 的抽象示意」——这些是开发期备注，不进定稿。

**表格**：

- **归位**：参数 / 取值表放实验章节（仿真环境节），不放理论章节；符号表置于首现处或集中术语表。
- **表注 ≠ 正文 ≠ 脚注**：表注是表格自身的说明（紧跟表下、小字、"注："开头），不混入正文段落，也不是页面脚注（footnote，正文上标编号牵引）。不用 markdown 引用块 `>` 充当表注；转 LaTeX 用 `tablenotes` / `threeparttable`。
- **无增量对照表删**：仅为论证某个实验选择（如「统一报 ep40k 而非 best」）而列的对照表，若结论可一句话讲清，删表留一句说明。

## 四、方法命名一致性

- **整体方法要有统摄名**：不把子模块缩写拼接当整体框架名（「SATCPP-UAR 双模块协同方法」）。给整套方法一个命名，子模块是其下层次（如 SUAC = SATCPP + UAR，SATCPP / UAR 为其下感知 / 路由模块）。
- **全文一致**：整体方法名在标题、摘要、引言贡献、方法总览、结论各处统一；改名须全文同步，不留拼接残留。命名是作者的品牌决策——可建议候选，但定名由作者拍板。

## 五、术语领域惯例

- 用目标领域 / 期刊的通用术语，不生造、不滥用小众译法。例：消融实验的各配置，CS / MARL 中文论文通用「实验组 / 配置」；「实验臂」（arm，源自多臂赌博机 / 临床试验）虽非错但不通用，徒增阅读负担。
- 术语首现给「全称（缩写）」；缩写命名风格与已有模块一致。

## 六、去结构冗余（与 `ai-tone-guardrails.md` 互补）

`ai-tone-guardrails.md` 查"词级 AI 腔"，本节补"句 / 段结构"层冗余：

- **章节导引 / 预告**：「以下 §3 给出…§4 给出…§5 给出…」目录式导引，删（目录已列节）。
- **清单式硬编号**：「其一（感知层）…其二（行动层）…其三…」——改连贯论述（「感知层面…行动层面…而最关键的闭环层面…」）。
- **赘述总结句**：「换言之，策略须先…再…方能…」——前文已述的换词重述，删。
- **自我标榜 / 口语收束**：「据我们所知…这正是本文 X 的切入点」「三缺口—三回应」之类——删或改客观陈述。

## 一句话

理论归理论、实验归实验、代码不入论文；符号首次定义才用；图说只标名、表注归表注；方法一个名、术语随领域；结构不堆目录与清单。
