安装与使用

前置：Claude Code（cc）或 pi；git。按场景四选一，都不用改本仓库内容。

推荐一键安装（cc · 实体拷贝，无软链）

# 全部安装（macOS / Linux / Windows Git Bash 通用）
curl -fsSL https://raw.githubusercontent.com/yjmm10/lusca-skill/main/scripts/install.sh | bash

# 只装想要的（空格分隔名字）
curl -fsSL https://raw.githubusercontent.com/yjmm10/lusca-skill/main/scripts/install.sh | bash -s -- lucas-paper-read lucas-paper-blog

装到 ~/.claude/skills/，所有项目可用；重复运行即整目录更新。

Plugin marketplace（cc 官方分发渠道 · 可版本管理）

/plugin marketplace add yjmm10/lusca-skill
/plugin install lucas-skills@lucas-skill

指令带插件前缀（如 /lucas-skills:lucas-paper-read）；按 description 自动触发不受影响，/plugin 面板里可随时升级/卸载。

pi 用户

git clone https://github.com/yjmm10/lusca-skill && cd lusca-skill
./scripts/link-pi.sh   # 一次性注册，之后新增 skill 自动发现（仅 pi 内 /reload 生效）

维护者克隆 + 软链（单一源开发，改一处处处最新）

git clone https://github.com/yjmm10/lusca-skill && cd lusca-skill
./scripts/link-project.sh   # 仅本仓库内可用（项目级 .claude/skills/）
./scripts/link-global.sh    # 任意目录开 cc 都可用（~/.claude/skills/）

软链在 Windows 需开发者模式或 WSL——只想用 skill 请选上面的一键安装；脚本幂等，遇实体冲突报错不覆盖（--dry-run 预览）。只改 SKILL.md 正文无需重跑，新开会话即生效。

首次使用：先到首页「快速上手」完成 clone + link 挂载，本页的斜杠指令才能在会话里触发。

Claude Code 多 Skill 工作区 · 单一源，处处最新

本仓库用单一源 + symlink 发现层维护多个 Claude Code（cc）与 pi skill：所有 skill 源只在 skills/<category>/<name>/，.claude/skills/、~/.claude/skills/ 一律是符号链接——改动只发生在唯一源，所有发现层即时同步，从根上杜绝「改了这份忘了那份」。

技能按论文科研 / 写作发布 / 调研 / 工程脚手架 / 元技能五线管理，覆盖论文检索、解析、精读、润色、LaTeX、海报，到论文与报告博客化、技术教程、事件调研，再到项目脚手架与产品官网的完整生产力链。
