快速上手：安装与挂载

前置：已安装 Claude Code（cc） 或 pi；git 与 bash（Windows 用 Git Bash / WSL）。

  1. 克隆仓库

    git clone https://github.com/yjmm10/lusca-skill
cd lusca-skill

  2. 挂载发现层（按需选一或叠加，均幂等可重复跑）

    ./scripts/link-project.sh   # 仅本仓库目录内可用（项目级 .claude/skills/）
./scripts/link-global.sh    # 任意目录开 cc 都可用（~/.claude/skills/）
./scripts/link-pi.sh        # pi 一次性注册，之后新增 skill 自动发现

  3. 新开会话验证：重开 cc / pi，输入斜杠指令 /lucas-paper-search 或直接说「帮我精读这篇论文」——能触发即安装成功。

  4. 日常更新

    git pull && ./scripts/link-project.sh   # 新增/删除 skill 目录后重建链接
# 只改 SKILL.md 正文：无需重跑，新开会话即生效

三条 link 脚本只建符号链接、不改内容；遇实体目录冲突会报错不覆盖（--dry-run 可预览）。

首次使用：先到首页「快速上手」完成 clone + link 挂载，本页的斜杠指令才能在会话里触发。
